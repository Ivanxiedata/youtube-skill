## hook
Antigravity Swarm: you think 3 separate files cost you 3 waits, but actually 3 agents code them at once, and usually another tests them before you look.

## before
Here's what changed. Before, one agent took users, orders and products in turn; after each, you ran the tests yourself.

## new
Now, in preview, you type /swarm, and your chat becomes the coordinator: it gives each file its own worker, at the same time, plus, usually, a verifier that runs the tests and sends problems back to the coder.
They all talk on one shared board you can watch: questions, test results.

## why
The catch: it works best when a task splits cleanly, and it uses your quota much faster.

## takeaway
So, what we learned: 3 files used to mean 3 waits; now, when the task splits, 3 agents take them at once, and usually a verifier tests first.
