You would never make a cook reread a five-hundred-page recipe binder before frying one egg. But that is how you prompt your AI agent. Agent Skills fix that.
In your kitchen, every rule you wrote sits in one giant binder: the one big prompt. Your cook reads all of it before every order.
The fix is a recipe box. Every recipe is a card with a tab: its name, and when to use it. Your cook reads only the tabs. Soup is ordered. He pulls the soup card, and nothing else.
Agent Skills work the same way. A skill is a folder with one file: skill dot M D. At startup, your agent loads only each skill's name and description. When a task matches, it reads the full instructions. Extra files load only if needed.
So it keeps many skills on hand, and a clear head for the job.
It is an open standard, started by Anthropic. But the lesson is as old as the kitchen. Don't tell your agent everything. Tell it where to look.
