Agent Skills in sixty seconds: you stop loading your one big prompt before each task; skills cost a hundred tokens until you need them, but how?
Here's how, in a kitchen. Every rule you wrote sits in one giant binder: your big prompt. Your cook rereads all of it, even to fry one egg.
Agent Skills are a recipe box. Every card has a tab: its name, and when to use it. Your cook reads only the tabs. Soup is ordered: he pulls only the soup card.
A skill is a folder with a skill dot M D file. At startup, your agent loads only each skill's name and description: about a hundred tokens. When a task matches, it reads the full instructions. Extra files load only if needed.
That's the how: only the tab loads, until a task needs the card. So your agent keeps many skills on hand, and room to work.
The lesson is as old as the kitchen. Don't tell your agent everything. Tell it where to look.
