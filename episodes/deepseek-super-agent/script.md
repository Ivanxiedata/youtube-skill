## hook
Watching one AI helper is easy. Watching ten is not. DeepSeek's Super-agent tries to fix that.

## before
Before, you sat with each AI coding session and told it every step. DeepSeek's team says one person can keep track of only three to five at once.

## new
Super-agent splits the job in two. One router agent stays in your team chat and on GitHub. When an allowed teammate asks for something, it opens a ticket and hands it to a worker: a separate agent with its own session and its own folder. Many workers run at the same time. The router stays quiet until a result is ready.

## why
Your attention is the bottleneck. Super-agent asks for it only when a person must decide, or can use a result.

## how
It is an open-source research prototype for one GitHub repo. Ask your coding agent to read its setup file and set it up with you.
