# Lesson: gpt-6-think-while-answering

Main idea (one sentence, at most about 25 words: what the viewer will think differently; not the headline, not the mechanism):
Harder thinking needn't mean a longer blank wait: the answer can start with what's found so far while the thinking goes on. (24 words)

Why it matters (to the viewer or the field, with the research.md row):
You can start reading sooner, parts that, OpenAI says, stay one answer as factual as one written all at once (row 4), instead of staring at "thinking" until one block lands (rows 2, 5): on web-search questions GPT-6 Instant starts answering 44% sooner on average than GPT-5.6 Instant (row 6);
and choosing harder thinking needn't push the start back: in OpenAI's internal test on everyday agent tasks, GPT-6 on Extra High started answering as soon as GPT-5.6 on Medium (row 7).

Misconception it corrects:
"A smarter answer must cost you a longer wait before you see anything." Said in the hook ("you think smarter answers cost you a longer blank wait,") and corrected in the same sentence ("but actually it can start answering before it's done thinking.", rows 1, 3).
