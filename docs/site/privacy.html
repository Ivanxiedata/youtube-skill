Privacy policy

Last updated: 2026-11-22. Applies to the "youtube-skill uploader" app (home page).

Who uses it

Only the owner of the YouTube channel Ivan Data, to publish that channel's own videos. It is not offered to anyone else.

What Google data it uses

  • youtube.upload: to upload the channel's videos and set their title, description and thumbnail.
  • youtube.force-ssl: to add caption files to those videos and read the channel's own name and id.

It does not read viewers' data, comments, subscribers, other channels, email or any other Google service.

Where data is kept

The sign-in token is stored only on the owner's computer and as an encrypted secret in the owner's GitHub repository, so the app can upload on a schedule. After each upload, the app saves the video's id, link and privacy setting in the repository. Nothing else from Google is stored.

Sharing

Google user data is never sold, shared with anyone, used for advertising, or used to train AI models. The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions; the stored token then stops working.

Contact

Questions: open an issue at github.com/Ivanxiedata/youtube-skill/issues.
